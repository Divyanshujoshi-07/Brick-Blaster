# Brick-Blaster


Brick-Blaster is an exciting arcade-style brick breaker game developed using HTML, CSS, and JavaScript. The game provides a smooth and engaging gameplay experience where players control a paddle to bounce a ball and destroy colorful bricks across the screen.

## Features
- Smooth and responsive controls
- Neon-themed modern UI
- Score tracking system
- Lives and game over system
- Collision detection and ball physics
- Interactive gameplay mechanics
- Fully responsive design
- Built using pure HTML, CSS, and JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Gameplay
Players must control the paddle, keep the ball in play, and break all the bricks to achieve the highest possible score. The game becomes more challenging as the speed and gameplay intensity increase.

## Purpose of the Project
This project was created to improve frontend development skills and demonstrate concepts like DOM manipulation, animations, collision detection, event handling, and game logic implementation using JavaScript.
